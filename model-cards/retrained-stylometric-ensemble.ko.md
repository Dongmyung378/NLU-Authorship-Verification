# 재학습한 문체 기반 앙상블

[English](./retrained-stylometric-ensemble.md) | [프로젝트 개요](../README.ko.md) | [최초 모델 카드](./stylometric-ensemble.ko.md)

이 카드는 문서가 분리된 명세에서 완료한 CPU 학습 및 모델 선택 실험과 별도의 고정 최종 평가를 설명합니다. 선택 표는 보정 전 임계값 0.5의 선택 집합 3,139쌍을 사용하고, 최종 평가 항목은 전체 모델과 기준을 함께 고정한 뒤 4,708쌍에서 측정했습니다. 최초 개발 성능은 별도 카드에 기록하며 이번 실험의 통제 비교 기준으로 사용하지 않습니다.

## 모델과 데이터

Dongmyung Park와 Juho Kim이 공동 개발한 XGBoost와 LightGBM 앙상블 구조를 유지했습니다. 최초 프로젝트 개발 기간은 2026년 2월부터 5월입니다. 트리 모델 두 개와 TF-IDF 변환기 세 개를 새로 학습했으며, 최초 과제 학습 가중치를 재사용하지 않았습니다.

| 항목 | 실제 구성 |
|---|---|
| 과업 | 영어 텍스트 쌍의 다른 저자 또는 동일 저자 라벨 분류 |
| 학습 집합 | 21,972쌍 |
| 선택 집합 | 3,139쌍 |
| 학습 시드 | 378, 단일 시드 |
| 선택한 특징 | 전체 특징, 28,512차원 |
| 앙상블 가중치 | XGBoost 0.25, LightGBM 0.75 |
| 선택 실험 임계값 | 확률 보정 전 0.5 |
| 저장된 XGBoost 트리 | 261개, 0부터 시작하는 최적 반복 260 |
| 저장된 LightGBM 트리 | 493개, 1부터 시작하는 최적 반복 493 |
| 직렬화 모델 묶음 | `artifact-inventory.json`을 포함한 파일 7개, 6,066,073바이트 |

단어와 문자 TF-IDF는 각각 특징 7,000개를 유지하고, 기능어 어휘는 219개입니다. 두 글의 절댓값 차이와 원소별 곱, 글마다 측정한 문체 특징 24개를 변환한 쌍 특징 72개, 코사인 거리 2개를 결합합니다. 변환기는 모두 학습 집합의 글에서만 맞췄습니다. 독립적인 [IDF 검증](../reports/stylometric-study/train-only-tfidf-proof.json)은 학습 쌍에 포함된 글 43,944회분의 문서 빈도로 저장된 IDF를 다시 확인합니다. 이 수치는 학습 쌍에서 사용한 글의 출현 횟수이며, 서로 다른 저자 수나 고유 문서 수를 뜻하지 않습니다.

[분할 명세](../reports/split-manifest.json)는 동일한 원문과 정규화된 문서를 공유하는 연결 요소를 집합별로 분리합니다. 저자 ID와 도메인 라벨은 제공되지 않았습니다. 최초 라벨 데이터의 과거 사용 이력과 문서 분리의 한계는 [평가 방법](../docs/evaluation.ko.md)에 설명합니다.

## 제한된 모델 선택 실험

[사전 계획](../reports/stylometric-study/predeclared-plan.json)은 학습 구성 4개, 최대 구성 모델 학습 8회, CPU 스레드 2개와 총 120분 예산을 고정합니다. 파일럿은 트리 상한 500개, 학습률 0.03과 선택 집합 로그 손실에 따른 최적 체크포인트를 공통으로 사용합니다. 전체 특징 파일럿의 XGBoost 깊이는 6이고 LightGBM 리프 수는 63입니다. 구성 모델별 시간 콜백 한도는 600초입니다.

전체 특징 확장 실험은 최초 방식의 XGBoost 7,000개와 LightGBM 2,000개 상한, 학습률 0.01, 깊이 7과 리프 127개를 사용하되, 구성 모델별 시간을 1,800초로 제한합니다. 상한 안에서 조기 종료와 시간 콜백이 실제 저장 체크포인트를 결정합니다. 시간은 반복 경계에서 확인하며, 보고서에는 실제 소요 시간과 시간 종료 여부를 남겼습니다.

최종 후보 XGBoost 가중치는 0.25, 0.5, 0.75로 제한해 두 모델을 모두 유지합니다. 가중치 0과 1은 단일 모델 진단에만 사용합니다. 전체 특징 50/50 파일럿보다 선택 집합 macro F1이 0.002 이상 높아야 후보를 채택합니다. 동점이면 전체 특징, 0.5에 가까운 가중치, 먼저 선언한 구성을 우선합니다. 확률 보정과 최종 평가 결과는 이 선택에 사용하지 않습니다.

| 선택 집합 실험 | 차원 | XGBoost / LightGBM | Macro F1 | 정확도 | 정답 |
|---|---:|---:|---:|---:|---:|
| 전체 특징 파일럿 기준 | 28,512 | 0.50 / 0.50 | 0.737298 | 73.85% | 2,318 / 3,139 |
| 선택한 전체 특징 파일럿 | 28,512 | 0.25 / 0.75 | 0.742355 | 74.32% | 2,333 / 3,139 |
| 코사인 거리를 포함한 TF-IDF 단독 파일럿 | 28,440 | 0.25 / 0.75 | 0.730061 | 73.11% | 2,295 / 3,139 |
| 문체 특징 단독 파일럿 | 72 | 0.25 / 0.75 | 0.643756 | 64.38% | 2,021 / 3,139 |
| 전체 특징 확장 구성 | 28,512 | 0.25 / 0.75 | 0.739923 | 74.10% | 2,326 / 3,139 |

선택한 앙상블은 50/50 기준보다 macro F1이 0.005056, 즉 0.5056%p 높았고 선택 집합에서 정답 15쌍이 늘었습니다. 확장 구성은 선택한 파일럿보다 성능이 높아지지 않아 채택하지 않았으며, 추가 학습도 진행하지 않았습니다. 이 수치는 단일 학습 시드에서 얻은 모델 선택 관측입니다. 특징 비교 표는 정해진 시간 한도에서 학습한 구성 전체를 비교하므로 저장된 트리 수가 달라질 수 있습니다. 이를 최종 일반화 성능이나 여러 시드의 통계적 검증 결과로 해석하지 않습니다.

[기계가 읽을 수 있는 특징 비교 보고서](../reports/stylometric-study/feature-ablation.json)에는 모든 허용 가중치와 단일 구성 모델 진단이 포함돼 있습니다. 전체 체크포인트 곡선과 원본 근거는 [완료 보고서](../reports/stylometric-study/completion.json)에 보존했습니다.

## 저장 모델과 실행 환경 검증

전체 CPU 실험과 저장 모델 검증에는 5,703.518초, 즉 95.06분이 걸렸습니다. 전체 과정에서 측정한 프로세스 최대 작업 메모리는 10,805,551,104바이트, 즉 10.06 GiB였습니다. 선택한 구성의 학습 시간은 각각 600.728초와 367.317초였습니다. XGBoost는 시간 한도에 도달한 뒤 최적 트리 261개를 저장했고, LightGBM은 상한 500개 안에서 493개를 저장했습니다. 채택하지 않은 확장 구성은 트리 681개와 1,389개를 저장했으며 두 모델 모두 30분 콜백 한도에 도달했습니다.

학습은 격리된 Windows CPU 환경에서 Python 3.12.15, NumPy 1.26.4, SciPy 1.16.3, scikit-learn 1.6.1, joblib 1.5.3, XGBoost 3.2.0과 LightGBM 4.6.0으로 실행했습니다. 정확한 정보는 [환경 기록](../reports/stylometric-study/cpu-environment.json)에 제공합니다.

저장한 앙상블을 다시 불러와 선택 집합 3,139쌍을 실제로 예측했습니다. 기록된 구성 모델의 가중 합과 최대 확률 차이가 0.0이었고, 두 글의 순서를 실제로 바꾼 경우에도 최대 확률 차이가 0.0이었습니다. 선택한 모든 파일의 크기와 SHA256을 확인했으며, 학습 코드와 의존성 파일 10개의 해시도 유지됐습니다. 이는 선택 집합에서 수행한 실제 저장 모델 검증입니다. 추가 환경에서 최종 모델을 재실행한 근거는 전체 모델의 공개 검증이 끝난 뒤 별도로 기록합니다.

[실험 요약](../reports/stylometric-study/summary.json), [모델 파일 명세](../reports/stylometric-study/artifact-inventory.json), [선택한 구성](../reports/stylometric-study/selected-configuration.json), [공개 근거 파일 명세](../reports/stylometric-study/public-evidence-inventory.json)에 정확한 측정값과 해시를 제공합니다. 보고서에는 메타데이터를 담았으며, 모델 바이너리와 개인 절대 경로, 개인 작업 일지를 포함하지 않았습니다. 외부 폴더의 원본 검증 자료도 수정하지 않고 보존했습니다.

## 고정한 최종 평가

전체 모델과 판단 기준을 함께 고정한 뒤 최종 4,708쌍 중 3,491쌍을 맞혔습니다. 정확도는 74.1504%, macro F1은 0.741498입니다. 보정 전 AB와 임계값 0.5에서는 F1 0.743335, 정답 3,503쌍이었습니다. 별도로 적합한 temperature 0.834865와 임계값 0.453506은 NLL을 0.481949에서 0.477097, ECE를 0.032128에서 0.019479로 줄였지만 정답 수는 12쌍 줄었습니다. 확률 보정 개선이 분류 성능 향상을 뜻하지는 않습니다.

고정한 판정 보류 기준은 3,858쌍을 판정해 처리 비율 81.9456%, 해당 정확도 79.3675%를 기록했고 850쌍을 보류했습니다. 처리 비율 80% 이상에서 정확도 90% 이상을 확보하는 목표에는 미달했으며 최종 평가로 다시 조정하지 않았습니다. 원래 추론과 고정 파이프라인 모두 AB/BA 확률 차이는 0입니다. 같은 데이터와 학습 한 번을 조건으로 문서 그룹을 함께 표집한 1,000회 분석의 macro F1 95% 구간은 0.723662~0.758584입니다.

[실측 결과](../docs/results.ko.md), [릴리스 요약](../reports/release-summary.json)과 [bootstrap 근거](../reports/evaluation-bootstrap.json)에 수치를 제공합니다. Windows와 Ubuntu WSL2에서 각각 최종 4,708쌍 전체 재검증을 완료했고 원래 비교 허용 오차를 충족했습니다. 같은 물리적 컴퓨터의 두 환경에서 측정한 지연 시간과 전체 프로세스 메모리는 [CPU 요약](../reports/cpu-reproduction.json)에 연결했습니다. 별도로 완료한 공개 다운로드 확인은 [재현 안내](../docs/reproduction.ko.md)에서 설명합니다.

## 해석 범위

제공된 영어 글 쌍의 동일 저자 라벨을 예측하는 모델입니다. 문서가 분리된 평가로 새로운 저자와 도메인의 일반화까지 입증하지 않으며 과거 데이터 사용도 공개합니다. 단일 시드의 선택 개선량으로 학습 시드의 불확실성을 평가할 수 없습니다. 최종 결과는 별도로 고정한 릴리스 근거에서 측정했으며 선택 점수에서 추정하지 않았습니다. 최초 개발 F1 0.7702와는 통제된 전후 비교가 아닙니다.
